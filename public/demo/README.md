# Realty AI — Demo

A self-contained, ~90-second animated product demo, in two languages:

- `index.html` — English
- `hindi/index.html` — Hinglish (same script, adapted, narrated in Hindi)

Each links to the other from its start screen. Open either in a browser (or
serve the folder with any static server) and click **Start Demo**. It plays
through: the problem, the WhatsApp chat, a live voice call, instant calendar
booking, the dashboard, and a closing CTA.

- Narration is real Sarvam TTS audio (`audio/*.wav` in each language folder,
  generated by that folder's `generate-audio.js` — rerun it if you want to
  change the script or voices).
- Background ambience and sound effects are synthesized live in the browser
  with the Web Audio API (see `script.js`) — no external audio files, no
  licensing to worry about.
- Both versions share one stylesheet (`style.css`) so visuals stay identical.
- To turn either into an actual video file: open it, click Start, and
  screen-record the tab (with system audio) using any screen recorder
  (e.g. OBS, or your OS's built-in recorder).

To preview locally:
```bash
cd demo
python -m http.server 8899
# English: http://localhost:8899
# Hindi:   http://localhost:8899/hindi/
```
